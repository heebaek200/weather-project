# 오늘 인간이 밖에 나가도 되는가

지역명을 입력하면 현재 날씨를 조회하고, 복장과 우산 필요 여부, 야외 활동 가능성, 오늘의 한 줄 판정을 보여주는 Vanilla JavaScript 날씨 웹 애플리케이션입니다.

이 프로젝트는 `fetch()`, `async / await`, JSON, 조건문, 함수 분리, DOM 조작과 외부 REST API 사용법을 복습하기 위해 제작했습니다.

## 기술 스택

- HTML
- CSS
- Vanilla JavaScript
- Fetch API
- Open-Meteo Geocoding API
- Open-Meteo Forecast API

React, Vue, jQuery, Axios 등의 프레임워크와 외부 라이브러리는 사용하지 않습니다.

## 파일 구성

```text
weather-project/
├─ SPEC.md
├─ readme.md
├─ index.html
├─ app.js
└─ app.css
```

- `index.html`: 검색 폼, 결과 영역과 날씨 배경 효과 요소
- `app.js`: API 요청, 날씨 데이터 정리, 조건별 판정과 DOM 출력
- `app.css`: 파스텔 UI, 반응형 레이아웃, 날씨별 배경과 애니메이션
- `SPEC.md`: 프로젝트 목표와 단계별 구현 명세

## 실행 방법

별도의 패키지 설치나 빌드 과정이 필요하지 않습니다.

1. 저장소를 내려받습니다.
2. `index.html`을 브라우저에서 열거나 정적 파일 서버로 실행합니다.
3. 부산, 김해시, 양산시처럼 지역명을 입력합니다.
4. `날씨 조회` 버튼을 누릅니다.

지역 검색 결과가 여러 개인 경우 Open-Meteo가 반환한 첫 번째 결과를 사용하므로, 동명이 있는 지역은 `이천시`처럼 구체적으로 입력하는 것이 좋습니다.

## 사용자 흐름

```text
지역명 입력
    ↓
Geocoding API로 지역 검색
    ↓
위도와 경도 획득
    ↓
Forecast API로 현재 날씨 조회
    ↓
날씨 데이터와 생활 조언 생성
    ↓
DOM 결과 및 날씨별 배경 출력
```

## 조회하는 날씨 데이터

- 현재 기온
- 체감 온도
- 강수 확률
- 풍속
- WMO 날씨 코드
- 낮·밤 여부

풍속은 `wind_speed_unit=ms`를 지정해 `m/s` 단위로 표시합니다.

## 구현된 기능

### 지역 및 날씨 조회

- 지역명을 위도와 경도로 변환
- 검색 결과 중 첫 번째 위치 사용
- HTTP 응답 상태 확인
- 현재 날씨에 필요한 항목만 요청
- 조회 중 버튼과 입력창을 잠가 중복 요청 방지
- 빈 입력, 검색 결과 없음, API 오류를 사용자 메시지로 표시

### 날씨 판정

`getClothingAdvice()`는 체감 온도를 기준으로 복장을 추천합니다.

| 체감 온도 | 추천 |
|---|---|
| 28℃ 이상 | 반팔과 모자 |
| 23℃ 이상 | 반팔 또는 얇은 긴팔 |
| 17℃ 이상 | 긴팔 또는 얇은 겉옷 |
| 12℃ 이상 | 자켓 또는 가벼운 외투 |
| 5℃ 이상 | 코트 또는 두꺼운 외투 |
| 5℃ 미만 | 패딩 또는 겨울 외투 |

`getUmbrellaAdvice()`는 강수 확률을 다음처럼 구분합니다.

| 강수 확률 | 판정 |
|---|---|
| 70% 이상 | 우산 필수 권장 |
| 50% 이상 | 우산 권장 |
| 20% 이상 | 장시간 외출 시 우산 고려 |
| 20% 미만 | 우산 없이 외출 가능 |

`getOutdoorAdvice()`와 `getTodayVerdict()`는 강수 확률, 풍속과 체감 온도를 함께 사용합니다. 비, 강풍, 극한 온도처럼 영향이 큰 조건부터 확인해 하나의 핵심 안내를 제공합니다.

## 날씨별 배경 효과

Open-Meteo의 WMO 날씨 코드를 다음 테마로 변환합니다.

| 상태 | 배경 효과 |
|---|---|
| 맑은 낮 | 밝은 크림·하늘색 배경과 빛나는 태양 |
| 맑은 밤 | 라벤더 계열 배경과 달 |
| 부분적으로 흐림 | 태양 또는 달과 움직이는 구름 |
| 흐림 | 솜사탕 형태의 구름 |
| 안개 | 차분한 회색 배경과 안개 띠 |
| 비 | 어두운 청회색 배경과 움직이는 빗방울 |
| 눈 | 밝고 차가운 배경과 눈송이 |
| 뇌우 | 비보다 어두운 남보라색 배경과 약한 번개 |
| 강풍 | 지구와 구름의 이동 속도 증가 |

테마 판정은 다음 우선순위를 사용합니다.

```text
뇌우 코드
→ 눈 코드
→ 비 코드 또는 강수 확률 70% 이상
→ 맑음, 구름, 안개
```

따라서 현재 날씨 코드가 부분 흐림이어도 강수 확률이 70% 이상이면 사용자 안내와 일치하도록 비 테마를 표시합니다.

## UI와 애니메이션

- 파스텔 색상의 동화풍 디자인
- 배경에서 천천히 움직이는 지구 이모지
- 투명한 글라스 스타일의 본문 및 결과 카드
- 데스크톱 기본 뷰포트에서 전체 결과가 한 화면에 표시되는 압축 배치
- 모바일에서는 가독성을 위해 한 열 중심의 세로 배치
- 조회 전 앱 카드를 화면 중앙에 배치
- 응답 후 결과 영역이 위아래로 펼쳐지는 애니메이션
- `.weather-project` 카드 hover 시 `scale(1.025)` 확대와 그림자 강조
- 날씨 변경 시 1.8초 동안 배경 색상을 천천히 전환

고정된 대각선 빗금은 의미가 불분명하고 움직이는 빗방울과 겹쳐 보이는 문제가 있어 제거했습니다.

## 접근성 및 사용성

- 상태 및 결과 영역에 `aria-live` 적용
- 장식 요소에 `aria-hidden` 적용
- 키보드 Enter로 검색 가능
- `textContent`를 사용해 API 데이터를 안전하게 출력
- `prefers-reduced-motion` 설정에서는 배경, 카드와 결과 애니메이션 비활성화
- 모바일에서는 비와 눈 입자 수를 줄여 화면 복잡도와 성능 부담 완화

## 주요 JavaScript 함수

```text
searchLocation()       지역명 → 위치와 좌표
fetchWeather()         좌표 → 현재 날씨
getWeatherTheme()      날씨 데이터 → 배경 테마
applyWeatherTheme()    body에 날씨 테마 적용
getClothingAdvice()    복장 추천
getUmbrellaAdvice()    우산 추천
getOutdoorAdvice()     야외 활동 판정
getTodayVerdict()      오늘의 한 줄 판정
showWeather()          결과 DOM 출력
showError()            오류 메시지 출력
searchWeather()        전체 비동기 흐름 제어
```

## 프로젝트 방향

이 프로젝트의 핵심은 정밀한 기상 서비스를 만드는 것이 아니라, 서로 따로 배운 JavaScript 기능이 실제 웹 애플리케이션 안에서 어떻게 연결되는지 이해하는 것입니다.
